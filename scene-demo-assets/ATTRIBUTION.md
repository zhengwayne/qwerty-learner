# Scene demo art attribution

- Style: children's picture-book soft clay / needle-felt look.
- Stills generated with `gpt-image-2.6-sunburst` via an OpenAI-compatible gateway (`/v1/images/generations` for masters, `/v1/images/edits` for action frames).
- Animations are **post-processed composites** of those stills (aligned cutouts → short loop as animated WebP + GIF fallback). They are not native model GIF output.
- No API keys are stored in this repository or the frontend bundle.
